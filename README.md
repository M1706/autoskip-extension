# AutoSkip — Chrome Extension
Automatically clicks skip buttons on YouTube and other video sites the moment they appear.

## Install
1. Click the green **Code** button → **Download ZIP**
2. Unzip the downloaded file
3. Open Chrome → go to `chrome://extensions/`
4. Enable **Developer mode** (top right toggle)
5. Click **Load unpacked** → select the unzipped folder
6. Done! The green AutoSkip icon will appear in your toolbar.

## Supported Sites
YouTube, Hotstar, Tubi, Peacock, Pluto TV, and more.
